# Lab 3 — Authentication + CRUD

Lab 3 được thêm vào thư mục [`lab3-auth-crud`](./lab3-auth-crud/), giữ nguyên source của bài thực hành số 1 ở thư mục gốc.

Nội dung chính:

- React đăng ký/đăng nhập, validate, React Context và localStorage.
- ASP.NET Core Web API với các endpoint POST, GET, PUT, DELETE.
- EF Core + SQLite và migration `InitialCreate`.
- Báo cáo Word: [`Bao_cao_Lab3_Auth_CRUD.docx`](./lab3-auth-crud/Bao_cao_Lab3_Auth_CRUD.docx).

## Chạy Lab 3

```bash
cd lab3-auth-crud
docker compose up
```

- Frontend: http://localhost:5173
- Swagger: http://localhost:5000/swagger

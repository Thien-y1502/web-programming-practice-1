# Web Programming Practice 1

Public frontend submission for the first Web Programming practice exercise.

## Requirements covered

- React project created with Vite
- Homepage styled with a separate CSS file
- Reusable components and four routed pages
- React Router navigation through the menu
- Direct URL access to `/about-us`, `/program`, and `/contact`
- Responsive layout for desktop and mobile

All names, dates and event information are fictional sample content. The repository does not contain private data, backend services, environment variables or production configuration.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
